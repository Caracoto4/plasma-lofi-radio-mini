# Lofi Radio Mini — виджет для KDE Plasma 6

Минималистичный виджет lofi-радио для рабочего стола KDE Plasma 6.  
Клон [plasma-lofi-radio](https://github.com/Caracoto4/plasma-lofi-radio) с чистым дизайном в стиле системных виджетов Plasma.

## Возможности

- **Прямая трансляция.** Воспроизведение потока с `live.lofiradio.ru` через QtMultimedia. Станция: _lofi hip hop_ (128 kbps).
- **Живые названия треков.** Icecast передаёт название песни в формате `StreamTitle='Artist - Title'`, который бэкенд FFmpeg в Qt не предоставляет. Небольшой вспомогательный скрипт на Python (только стандартная библиотека) читает метаданные из сокета и отдаёт их в формате JSON на `127.0.0.1`, чтобы виджет мог показывать текущий трек.
- **Уведомления о смене трека.** При смене трека появляется системное уведомление с названием и исполнителем. В настройках есть переключатель «Показывать уведомление при смене трека».
- **Сохранение состояния.** Громкость и состояние воспроизведения сохраняются между перезапусками Plasma.
- **Проверка обновлений.** В настройках виджет запрашивает `metadata.json` с GitHub, сравнивает версию и показывает кнопку «Установить», если доступна новая версия.
- **Обновление одним нажатием.** Кнопка «Установить» в настройках запускает `update.sh`, который обновляет виджет, helper-скрипт и перезапускает Plasma.
- **Удобное обновление.** Скрипт `update.sh` автоматически обновляет виджет, helper-скрипт и перезапускает сервисы. Повторные запуски используют `git fetch` + `reset --hard`, не удаляя клон.
- **Минималистичный дизайн.** Чистый интерфейс без лишних элементов — только название трека, кнопка play/pause и громкость. Используются системные цвета Kirigami.
- **Бегущая строка.** Название трека прокручивается, если не помещается в отведённое место.
- **Автопереподключение.** Если поток прерывается, виджет автоматически восстанавливает соединение.
- **Два режима.** Работает как виджет на рабочем столе (260×180) и как иконка на панели (34×34).
- **Единый движок.** Потоковый движок реализован как QML _singleton_, поэтому карточка на рабочем столе, иконка на панели и всплывающее окно используют один `MediaPlayer` и одно сетевое соединение.

## Отличия от оригинала

| plasma-lofi-radio | lofi-radio-mini |
|---|---|
| Виниловая пластинка с вращением | Нет декоративных элементов |
| Тонарм с анимацией | Нет тонарма |
| Анимированный эквалайзер | Нет эквалайзера |
| Градиентный фиолетовый фон | Прозрачный фон |
| Две станции с переключением | Одна станция |
| Кнопки prev/next | Только play/pause |
| Размер: 296×452 px | Размер: 260×180 px |
| Сложные Canvas-рисунки | Нативные Kirigami-компоненты |

## Требования

| Компонент | Версия / Примечание |
| :-- | :-- |
| **KDE Plasma** | 6.0 или новее |
| **Qt** | Qt 6 с `qt6-multimedia` (бэкенд FFmpeg) |
| **Kirigami** | QML-модуль `kirigami` (устанавливается вместе с `plasma-workspace`) |
| **Python** | 3.8+ — только для вспомогательного скрипта, только стандартная библиотека, без pip-пакетов |
| **systemd** | Опционально, но рекомендуется для постоянной работы вспомогательного скрипта |

## Установка

### Первая установка

```bash
git clone https://github.com/Caracoto4/plasma-lofi-radio-mini.git
cd plasma-lofi-radio-mini
chmod +x install.sh
./install.sh
```

Скрипт устанавливает всё в домашнюю директорию, поэтому **права root не требуются**:

- `~/.local/share/plasma/plasmoids/org.koda.lofiradio.mini` — виджет
- `~/.local/share/lofi-radio-mini/lofi-nowplaying.py` — вспомогательный скрипт для названий треков
- `~/.local/share/lofi-radio-mini/update.sh` — автономный скрипт обновления (работает без клона репозитория)
- `~/.local/share/lofi-radio-mini-src/` — клон репозитория (создаётся при первом обновлении через виджет)
- `~/.config/systemd/user/lofi-nowplaying.service` — пользовательский сервис для скрипта

После установки добавьте виджет: щёлкните правой кнопкой мыши по рабочему столу или панели → **Добавить виджеты…** → **Lofi Radio Mini**.

Если виджет не появился в списке, перезапустите оболочку:

```bash
systemctl --user restart plasma-plasmashell.service
```

### Обновление

**Автоматическое обновление (рекомендуется):**

1. Правый клик по виджету → **Настроить Lofi Radio Mini...**
2. Нажмите **Проверить обновление** — виджет запросит `metadata.json` с GitHub и сравнит версию
3. Если доступна новая версия, появится кнопка **Установить X.Y.Z** — нажмите её
4. Будет запущен `update.sh`, который скачает последнюю версию, установит её и перезапустит Plasma

Процесс обновления (фактическое поведение `update.sh`):
- Если клон репозитория уже есть — делает `git fetch` + `reset --hard` (не удаляя папку)
- Если клона нет — клонирует репозиторий из GitHub
- Устанавливает виджет через `kpackagetool6 --upgrade`
- Копирует helper-скрипт и сервис systemd
- Перезапускает Plasma (`systemctl --user restart plasma-plasmashell.service`)
- Перезапускает helper-сервис (отложенно, чтобы не убить сам процесс обновления)

Важно: после нажатия кнопки Plasma перезапустится — несохранённое состояние рабочего стола может быть потеряно.

**Ручное обновление:**

```bash
cd plasma-lofi-radio-mini   # ваша копия репозитория
git pull
chmod +x install.sh
./install.sh                # ставит виджет, helper и update.sh, перезапускает сервис
                            # (update.sh теперь работает автономно и использует git fetch + reset)
systemctl --user restart plasma-plasmashell.service
```

## Удаление

```bash
./uninstall.sh
```

Экземпляр виджета, уже размещённый на рабочем столе или панели, необходимо удалить вручную: щёлкните по нему правой кнопкой мыши → **Удалить виджет**.

## Вспомогательный скрипт `lofi-nowplaying.py`

Скрипт поддерживает одно долгоживущее соединение с потоком Icecast, пропускает аудиобайты и публикует каждый блок метаданных, который видит:

```
GET http://127.0.0.1:8731/nowplaying.json

{
  "raw": "dryhope - Shade",
  "artist": "dryhope",
  "title": "Shade",
  "station": "LoFi Radio",
  "stream": "http://live.lofiradio.ru:8000/lofi_mp3_128",
  "updated": 1792329532,
  "connected": true,
  "port": 8731
}
```

Скрипт слушает только `127.0.0.1`, пытается использовать порты `8731`, `8732`, `8733` по порядку и отвечает `ok` на `GET /health`. Фактический порт публикуется в поле `port`, а виджет запоминает его — если `8731` занят другим процессом, уведомления и кнопка «Проверить обновление» продолжат работать на резервном порту. При обрыве соединения скрипт переподключается с экспоненциальной задержкой.

Дополнительные эндпоинты (доступны только локально, CORS разрешён лишь для localhost-источников):

- `POST /notify` — показывает системное уведомление о смене трека от имени виджета;
- `POST /update` — запускает `~/.local/share/lofi-radio-mini/update.sh` (обновление одним нажатием из настроек виджета); параллельный запуск блокируется. Helper перезапускается отложенно через `systemd-run`, чтобы не убить сам процесс обновления.

Проверка статуса и логов:

```bash
systemctl --user status lofi-nowplaying
journalctl --user -u lofi-nowplaying -f
```

Виджет опрашивает скрипт каждые 5 секунд, когда helper доступен (и каждые 2 секунды, пока тот не ответит — чтобы подхватить резервный порт).

> **Важно:** аудио не проходит через вспомогательный скрипт. Если скрипт не работает, музыка всё равно будет играть, но без отображения названий треков.

## Структура репозитория

```
package/                          Пакет Plasma (устанавливается через kpackagetool6)
├── metadata.json                 id, имя, версия, категория
├── contents/
│   ├── config/
│   │   ├── config.qml            Определяет вкладки настроек (ConfigModel)
│   │   └── main.xml              Конфигурация виджета (громкость, autoplay, notifications)
│   └── ui/
│       ├── main.qml              Апплет: полное представление + компактное для панели
│       ├── configGeneral.qml     Вкладка «General»: автозапуск, уведомления, проверка обновлений
│       └── components/
│           ├── qmldir            Объявляет модуль org.koda.lofiradio.mini и синглтон StreamPlayer
│           ├── StreamPlayer.qml  QML-синглтон: MediaPlayer, поток, опрос названий
│           └── PlayerCard.qml    Минималистичная визуальная карточка (не зависит от Plasma)

helper/
├── lofi-nowplaying.py            Метаданные Icecast -> JSON на localhost + /notify, /update
└── lofi-nowplaying.service       Юнит systemd для пользователя

install.sh                        Устанавливает виджет, helper и сервис
update.sh                         Автономный скрипт обновления (fetch + reset + install + restart)
uninstall.sh                      Удаляет виджет, helper и сервис
```

Файлы `index.html`, `src/`, `package.json`, `vite.config.js` — лендинг (React + Vite), к установке виджета не относятся.
